# 帝王心术 v0.4 · 决策判决框架（prompt-only）

> 把过往的决策复盘（奏折）蒸馏成四台决策函数，按路由表输出**结构化判决令**。整份喂入 system prompt 即可独立运行，不依赖任何外部服务（Jev 校准层为可选外挂）。

## 为什么做这件事

- 决策复盘散在聊天记录里，不可复用；拆成「四台决策函数 + 路由表 + 输出契约」后，同一个局可以反复跑、可比对。
- 通用大模型的建议常见病症是「放在任何局都成立」的零信息句。所以给输出加硬约束：**必须含具体数字、具体人位、具体期限，并能被 3 条带日期的预测证伪**。

## 结构总览

```
role            → 定位：判决机器，不是问答助手
redline         → 四类不可逆动作命中即中止，转「事实清单 + 拖延成本」
assumptions     → 信息不足时允许自补，最多 3 条
machines        → 四台决策函数（雍正/康熙/乾隆/嘉靖）
route_table     → 局型 → 主裁/辅裁
weight_algorithm→ 混合局按确定性算法算权重，禁止心算
adjudication    → 主裁出结论，辅裁可否决；终审规则
variable_override→ 亲密关系 / 强弱不对等局换参
output_contract → 判决的固定结构（令/假设/五段/价/锚）
failure_cards   → 10 张「死法卡」，命中即判决作废
anti_barnum     → 反巴纳姆防线（特异性测试 + 反向测试）
validation_spec → 回归集规格（当前状态：未跑）
jev_integration → 可选：原子判断外包给校准模型取概率
```

## 四台决策函数

| 机器 | 内核 | 看什么 | 明确不裁（否决域） |
|---|---|---|---|
| **雍正** | 一切局折算成钱粮账 | 数字、期限、责任名单；忠诚/情绪/愿景全部折价 | 对外叙事与面子定价、多方派系制衡 |
| **康熙** | 先问「动了会不会乱」，再问「值不值得动」 | 结构、关系网、连环崩的可能性 | 期限小于 7 天的快速止损局（耐性是负资产） |
| **乾隆** | 先定「怎么被讲」，再定「怎么做」 | 可叙述性、谁能当刀、证据链 | 无观众、无第三方评价的纯财政核算 |
| **嘉靖** | 不表态而掌权，只收裁决权 | 派系、立场、谁求谁 | 双边一对一局（无人可互耗） |

基准权重（人工给定、未校准）：雍正 20 · 康熙 20 · 乾隆 30 · 嘉靖 30。

## 路由表

| 局的类型 | 主裁 | 辅裁 |
|---|---|---|
| 财政、追投、止损、账单 | 雍正 | 康熙 |
| 追责、人事收权、内部清理 | 雍正 | 乾隆 |
| 长期对抗、结构威胁、联盟 | 康熙 | 雍正 |
| 舆论、面子、借刀、脏活 | 乾隆 | 嘉靖 |
| 多方博弈、表态艺术、派系 | 嘉靖 | 乾隆 |
| 名分、立场选择 | 嘉靖 | 康熙 |

混合局（命中两行以上）按下述确定性算法计算，**禁止心算，必须写出中间值**：

```
score = {雍正:20, 康熙:20, 乾隆:30, 嘉靖:30}
for each 触发项 in 局:
    if 含 钱/期限/责任到人/代理成本:     score.雍正 += 10
    if 含 不可逆/长期/结构依赖/连环风险: score.康熙 += 10
    if 含 对外可见/第三方评价/需留退路:  score.乾隆 += 10
    if 含 多方/信息不对称/不能表态:      score.嘉靖 += 10
score = clamp(score, 10, 45); score = normalize(score, sum=100)
主裁 = argmax(score)；并列 → 取 雍正>康熙>乾隆>嘉靖 靠前者
```

三台以上同时触发 → 此局不可单次判决，拆成子局分别跑。

## 输出契约（固定结构）

```
令    一句话判决：做什么 + 期限 + 终止条件          ≤40 字
假设   自补项，最多 3 条，无则省略                  ≤50 字
① 度  账   单位｜成本｜阈值｜不可折                 ≤55 字
② 势  位   伤我｜必依我｜可替代｜退出成本           ≤55 字
③ 时  机   暴露｜反击力｜犯错率｜等待成本           ≤55 字
④ 术  手   给｜拿｜怎么说｜让谁知                   ≤55 字
⑤ 验  三条可证伪预测，带数字与日期                 ≤60 字
价    隐性成本（关系/名声/机会/时间）              ≤15 字
锚    机器归属 + score 中间值（+参数替换）          ≤30 字
```

硬规则：首句即判决；日期以 T0 + N 天的绝对日期写死；五段之间引用链强制带入；遮住令后五段独立可读。

## 10 张死法卡（命中即作废重算）

忠奸卡 · 面子通胀卡 · 弃刀后遗症卡 · 彻底解决卡 · 明君卡 · 代理幻觉卡 · 时间通胀卡 · 单点依赖卡 · 身份错位卡 · 冷度自噬卡

## 反巴纳姆防线

1. **特异性测试**：每条判断必须含「换个局就不成立」的字段——具体数字、具体人位、具体期限。三样全无的句子是运势，不是判决。
2. **反向测试**：把结论反过来读，若反面同样有道理且同样无法反驳，说明该句零信息量，删。
3. **正确废话清单**（出现即删）：「先算账再动手」「控制风险」「留有余地」「权衡利弊」「时机很重要」「知己知彼」。

## 与 G-E-F-V 循环的关系

本框架本身也按 G-E-F-V 运行：`generate` 出判决草稿 → `evaluate` 对照检查（死法卡/引用链/字数/红线）→ `repair` 修复 → 只有 evaluate 全过才输出，等于把「自觉检查」变成可复核的验收步骤。

## 可选外挂：Jev 校准层

Jev 只回答三类结构化问题（noul 是非 / choice 多选一 / score 2–10），不生成文本、不做算术、不读日期。做法：把 `evaluate` 段的检查项逐条转成 noul 问题调用，取回概率作为终审门槛（如 0.8，低于则按「未知」处理）。
注意：四选一不要用 choice 原语（校准审计显示 choice 系统性过度自信），改用「每台机器一个 noul + 概率归一」。

## 已知缺陷（如实声明）

1. 康熙/乾隆/嘉靖为行为反推，非亲笔文本支撑；只有雍正档有直接朱批依据。
2. 基准权重与浮动规则为人工给定，未校准。
3. 冲突裁决仅覆盖推演样本，未覆盖「三机同冲突」。
4. 层3 证据抽取无独立第二人复核。
5. **未做盲测**：四机是否优于裸模型尚未验证；回归集规格已定，一次未跑。

## 用法

1. 整份 README 的规则部分喂入 system prompt（或作为 skill 文件加载）。
2. 输入格式：`局：……。我要什么：……。约束：……。`
3. 输出即判决令，不需要额外追问。

## 可运行实现：`app/`（朕知道了 · 四帝判官）

把规则书套进 Jev 式判断架子的 Web 服务。模型只回答 11 道结构化判断题（choice 选一 / score 打分 / noul 是否，各带把握值），类型校验、分流和限流都写在代码里，不靠模型自觉。

| 文件 | 作用 |
|---|---|
| `app/server.js` | Node.js / Express：调 DeepSeek（JSON 模式）→ 选项白名单与数值范围校验，不合格带错误信息重试一次 → 按把握分流 → 按 IP 每日限流 |
| `app/prompt/wrapper.xml` | 外层架子：11 道题的选项、打分标尺、输出格式 |
| `app/prompt/rulebook.md` | 规则书 v0.3 全文（服务当前加载的版本） |
| `app/public/index.html` | 判决卡页面 |
| `app/test/` | 样例与模拟输出；`npm test` 跑 11 项校验与分流检查 |

分流规则：急性危机把握 ≥ 0.3 → 热线卡不判；需专业资质或手段违法 → 不判；不可逆把握 ≥ 0.5 → 只出事实清单；局型或主裁把握 < 0.5 → 只出补问；其余出判决卡。

```bash
cd app && npm install --omit=dev
export DEEPSEEK_API_KEY=你的key      # 没有 key 时改跑 npm run mock（模拟输出）
PORT=3100 node server.js
npm test
```

部署（pm2 + Nginx 反代）见 `app/README.md`。
